# flowy-piano

A piano learning app that teaches with Western (C D E) or Indian Carnatic sargam (Sa Ri Ga) notation.

| Folder | What it is |
|---|---|
| `ios/` | Native iOS app (Swift, SwiftUI): on-screen keyboard, MusicXML/MIDI import, guided lessons with microphone feedback. |
| `server/` | Sheet music recognition server: turns photos and PDFs of printed scores into MusicXML for the app. |
